# 🏥 Medical Tech Pro

Catálogo institucional B2B de equipamiento médico de alta complejidad (mesa quirúrgica, torre de laparoscopía 4K, monitor multiparamétrico), con lógica de cotización formal para instituciones de salud.

🔗 **[Ver demo en vivo](https://micaelaresolani.github.io/patient-triage-system/medical%20tech%20pro/index.html)**

## Tecnologías

`HTML5` · `CSS3` · `JavaScript`

## Características

- **Catálogo con fichas técnicas**: cada producto muestra certificación ANMAT/FDA y precio
- **Presupuesto tipo carrito**: acumula productos seleccionados y calcula el total
- **Formulario de cotización institucional**: permite elegir tipo de requerimiento (compra directa, licitación pública, renovación tecnológica)
- **Descarga de cotización en PDF**

## Cómo ejecutar localmente

```bash
git clone https://github.com/MicaelaResolani/patient-triage-system.git
cd "patient-triage-system/medical tech pro"
# Abrir index.html en el navegador
```
